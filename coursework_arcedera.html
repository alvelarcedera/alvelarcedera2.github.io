Web Design Coursework

In this section, my work done in Web Design is demonstrated, including those tasks and projects that have allowed me to learn more about website construction. By completing these outputs, I have gained experience in arranging content, linking pages, working with images and building forms by using HTML, CSS, and JavaScript.

My First Personal Web Page

For the activity, I created my own personal webpage for the very first time by making use of basic HTML, where I was able to introduce myself, along with my background and my interests such as music and multimedia arts. Headings, pictures, as well as my social networking sites, social media accounts, and my band's song lyrics were all included in the webpage.

Output link: Web Page (Demo)

Student Registration Form

In the activity, I designed a form to register students for events. It had different areas where students were required to fill in their personal details, educational details, preferences about events, and extra comments. Some of the input controls that I used included text boxes, date box, radio buttons, check boxes, drop-down boxes, and text box area to learn more about different input controls.

Output link: Form

CSS Media Queries

In this activity, I applied CSS media queries to make changes in a campus news website known as "The Daily Nonsense" to suit the screens of mobile, tablet, and desktop. I made changes in the navigation bar and created a layout of the news articles in two columns for large screens. The sidebar was also created to show on the desktop screen.

Output link: Responsive Web Design

HTML Lists

In this task, I used HTML lists in order to build a “Web Development Learning Roadmap” that includes such items as HTML Basics, Tables, Forms, CSS, JavaScript. I trained myself to use ordered, unordered, and nested lists that can help me to establish connections between various items and sub-items. Unfortunately, I did not manage to complete this assignment due to lack of time.

Output link: HTML Lists

Color Palette Switcher

In this exercise, I have used JavaScript to provide interaction in the color switcher, where we could choose between Sunset, Ocean, Berry, and Forest themes. Through this exercise, I have been able to practice the use of click listeners that change the background of the poster along with the mood label. But unfortunately, I have been successful in accomplishing just two out of the five necessary features.

Output link: Color Palette

Digital Sticker Sheet Generator

For this exercise, JavaScript was used for creating numbered stickers according to the number of the stickers required by the user. This worked well as the stickers were created, the counter was incremented, and the old sheet was replaced. I failed to implement the colors appropriately so that the stickers would change from being just the default color to pink, purple, and green.

Output link: Digital Sticker Sheet
